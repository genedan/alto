alto.ui.settings_menu

The building blocks of the settings panels that slide in beside an exercise.

A panel is a menu of rows (Clefs, Range, Key signatures …) that each lead to a page, in a SlideStack. This module has the rows, switches, checklists and editors those pages are made of, and the panels’ shared base classes: ExerciseSettingsPanel (navigation and saving), ClefsPanel (a Clefs page) and StaffRangePanel (a Range page per clef). The panels themselves are in alto.ui.settings_panel and alto.ui.pack_settings_panel.

Examples

>>> _key_label(2)
'D  ·  2♯'
>>> row = MenuRow("Clefs")
>>> row.title.text()
'<b>Clefs</b>'

clef_choice_page

def clef_choice_page(
    choices: Iterable[str],
    *,
    selected: set[str],
    edited: Callable[[], object],
    back: Callable[[], object],
    title: str = 'Clefs',
    hint: str = 'One of the checked clefs is picked at random.',
) -> tuple[dict[str, QCheckBox], QWidget]

Build the “Clefs” page that every exercise with a choice of clefs shares.

Parameters

  • choices (iterable of str): The clefs to offer, from settings.RANGE_KEYS; “grand” is left out of exercises that cannot use the grand staff.
  • selected (set of str): The clefs that start checked. Keyword-only.
  • edited (callable): Called whenever a box is checked or unchecked. Keyword-only.
  • back (callable): Called when the Back button is clicked. Keyword-only.
  • title (str, default “Clefs”): The page’s title. Keyword-only.
  • hint (str, default “One of the checked clefs is picked at random.”): The gray line above the list. Keyword-only.

Returns

  • dict of str to QCheckBox: The checkbox of each clef offered.
  • QWidget: The page, with its title. The last checked clef cannot be unchecked.

Examples

>>> checked = []
>>> boxes_, page_ = clef_choice_page(
...     ("treble", "bass"),
...     selected={"bass"},
...     edited=lambda: checked.append(1),
...     back=lambda: None,
... )
>>> boxes_["bass"].isEnabled()  # it is the only one checked, so it stays checked
False
>>> boxes_["treble"].setChecked(True)
>>> sorted(c for c, ticked_box in boxes_.items() if ticked_box.isChecked()), checked
(['bass', 'treble'], [1])
