alto.ui.colors

Mixing colors. The interface blends palette colors to get its soft tints and highlights.

Examples

>>> blend_name(QColor("#000000"), b=QColor("#ffffff"), t=0.5)
'#808080'

blend

def blend(
    a: QColor,
    *,
    b: QColor,
    t: float,
) -> QColor

Return the color a given fraction of the way from one color to another.

Parameters

  • a (QColor): The color at 0.
  • b (QColor): The color at 1. Keyword-only.
  • t (float): How far from a to b: 0 is a, 1 is b, 0.5 is halfway. Keyword-only.

Returns

  • QColor: The blended color.

Examples

>>> blend(QColor("#000000"), b=QColor("#ffffff"), t=0.0).name()
'#000000'
>>> blend(QColor("#ff0000"), b=QColor("#0000ff"), t=1.0).name()
'#0000ff'

blend_name

def blend_name(
    a: QColor,
    *,
    b: QColor,
    t: float,
) -> str

Return the hex name of a blended color, for use in a stylesheet.

Parameters

  • a (QColor): The color at 0.
  • b (QColor): The color at 1. Keyword-only.
  • t (float): How far from a to b. Keyword-only.

Returns

  • str: The color as ‘#rrggbb’.

Examples

>>> blend_name(QColor("#000000"), b=QColor("#ffffff"), t=1.0)
'#ffffff'
