    Getting started

    Operating system

    Install and run

    Linux download

    1. Download Alto for Linux for an x86-64 desktop. The archive includes Python and Qt.
    2. Extract the archive, open a terminal in the extracted folder, and run sh install.sh install.
    3. Open Alto from your application menu.

    The installer puts Alto in ~/.local/opt/alto and creates the command ~/.local/bin/alto for your account. For other processor architectures, see Running from a source checkout.

    Windows installer

    Windows code-signing certificate. We’re working on getting a certificate to sign Alto’s Windows installer. Until then, Windows may show Unknown publisher or block the installer before setup starts. Help with Windows installation warnings

    1. Download the 64-bit Windows installer for Windows 10 or 11.
    2. Open the downloaded .exe and follow the setup prompts.
    3. Open Alto from the Start menu.

    The installer includes Python and Qt and installs Alto for your account.

    Mac source installation

    On Mac, you can try Alto from source. macOS is currently untested. With Git and Python 3.11 or newer installed, open Terminal and run:

    git clone https://github.com/altosaurus/alto.git
cd alto
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m alto

    To open Alto again, run .venv/bin/python -m alto from the same alto folder.

    Check your download

    Download SHA256SUMS from the same release as your download. It lists the SHA-256 checksum of each file.

    In the folder containing the archive and SHA256SUMS, run:

    sha256sum --check --ignore-missing SHA256SUMS

    Look for OK after the archive name.

    Open PowerShell in the folder containing the installer. Use the exact name of the file you downloaded:

    Get-FileHash ".\alto-0.0.2-windows-x64-setup.exe" -Algorithm SHA256

    Open SHA256SUMS in Notepad and find the line naming that same .exe. Every character in its checksum should match the Hash printed by PowerShell (uppercase and lowercase are equivalent). If they differ, discard the installer and download it again from the official Alto release.

    Windows installer troubleshooting

    Edge says the download is uncommon

    An uncommon-download warning means Microsoft Edge has little download history for that file. Check that you started from the altosaurus/alto GitHub release. If you choose to keep the file, check its checksum before opening it. If the browser or antivirus identifies a specific threat, stop and leave the file blocked. Microsoft’s SmartScreen guidance

    “Windows protected your PC” or “Unknown publisher”

    If SmartScreen calls Alto an unrecognized app, select More info to see the filename and publisher. Unknown publisher is expected for the current unsigned installer. On your own PC, if the filename and checksum match the official release and you trust the download, choose Run anyway to start setup. Choose Don’t run if you’re unsure. How SmartScreen checks app reputation

    Windows blocks the installer with no “Run anyway” option

    On a work or school PC, your organization may control which apps can run. Give your IT team the Alto release link and the exact message so they can review it. If Windows 11 names Smart App Control, it has no per-app exception. Keep the protection enabled and check back for a signed release. Microsoft’s Smart App Control FAQ

    Setup stops at “Microsoft Visual C++ Runtime”

    Alto needs Microsoft’s x64 Visual C++ Redistributable. If setup asks for administrator permission for that component, check that the prompt identifies Microsoft Corporation as the publisher. If its download fails or you’re installing offline, get the x64 package from Microsoft, install it, restart if prompted, then run Alto’s installer again. Microsoft’s runtime download

    If you’re still stuck, include the Alto installer filename, your Windows version, and the exact message when you report an installation issue.

    Install as a program (Linux)

    To install from GitHub with uv, run sh scripts/alto-install.sh install from the repository. Open Alto from the application menu. Use sh scripts/alto-install.sh update to update the program and refresh its menu entry and icon. The in-app updater can update this installation too. Choose Follow the main branch in Settings → Updates to get changes before release. Packaged installations follow releases.

    Running from a source checkout

    For development, install Git and Python 3.11 or newer. Alto installs PySide6 and the other dependencies into the virtual environment. Run the following commands, then use git pull from the checkout to get source updates.

    git clone https://github.com/altosaurus/alto.git
cd alto
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m alto

    git clone https://github.com/altosaurus/alto.git
cd alto
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m alto

    Updating Alto

    Open ☰ → Tools and choose Check for updates… to check manually. Alto also checks for releases when the main grid is active, up to once every 24 hours. Settings → Updates shows your version and lets you turn automatic checks off.

    For a packaged installation, choose Yes to download an offered release, No for a reminder after 24 hours, or Don’t remind me again to skip it. Alto verifies the signature on SHA256SUMS with its built-in public key and checks the package against the signed list before installation. Press OK when prompted to restart.

    You can also unpack a newer archive and run sh install.sh install again. A failed installation keeps your previous copy. If you run Alto straight from the unpacked folder, download the new archive yourself.

    You can also run a newer Windows installer to update your copy.

    Close Alto and run these commands in Terminal from your alto folder to update the source and its dependencies:

    git pull
.venv/bin/python -m pip install -e .
.venv/bin/python -m alto

    Uninstalling Alto

    For the Linux download, run sh install.sh uninstall from the extracted folder. For the uv installation, run sh scripts/alto-install.sh uninstall from the repository. Both commands remove the program and its menu entry and keep your practice history and settings. Add --purge to delete them too.

    Open Settings → Apps, select Alto, and choose Uninstall. The uninstaller asks whether to also remove your practice history and settings.

    Quit Alto. If you no longer need the source checkout, move the cloned alto folder, including its .venv, to the Trash. Your practice history is stored separately in ~/Library/Application Support/Alto/alto.db.

    To keep a copy of your practice history and settings, choose Export backup… in Alto before uninstalling. Your data

    First launch

    The first time you open Alto it asks you to create a profile.

    Type a name and press Create profile. There is no password, and the name is only a label that keeps your history separate from anyone else who uses the same computer. Next time Alto opens straight into the profile you used last.

    To switch to someone else, or add another profile, open the menu (☰) and choose Profile.

    Alto includes the default Finale Maestro notation font. To use the optional Noto Music style, install the Noto Music font on your system and choose it in Settings.

    Your first session

    1. Click an exercise on the home screen.
    2. Follow the prompt. Click an answer button or use the shortcut in its tooltip. For a construction question, place the requested note or sign.
    3. A correct answer turns green. With the default scheduler, try a missed question again. With SM-2 or FSRS, a miss moves the card to the learning queue for a later retry.
    4. The counter at the top shows how many you have right and your current streak.

    The Exercises / Lessons control at the top left selects what to browse. Alto starts with tiles. Navigation Pane opens the matching list on the left; before you start an activity, the main panel says “Select an exercise to begin.” or “Select a lesson to begin.” Use the separate Tiles grid button to return to tiles without losing your place.

    The icon-only Exercises / Lessons pair sits at the top left, followed by an open/close navigation-pane button, a divider, and a separate grid button for returning to tiles. Hover over an icon to see its name. The search field below filters the selected section by name, description or category, and follows the sidebar’s width. On the tile grid or during an exercise, click the funnel icon at the right end of the search row to open the filter sidebar. Click it again to collapse the sidebar and keep your filters. The sidebar opens on the right with every category expanded. Check or clear a category to include or hide its activities, or check individual exercises or lessons. The tiles and navigation list show the same matches. A dash means some activities in a category are checked. All categories selects or clears the whole list.

    Turn on Shuffle exercises, just left of the funnel, to practice the exercises in your filtered list. After each right or wrong answer, Alto prefers an exercise from another category. If the other available exercises are in the current category, it picks one of those. For example, selecting only Note Identification and Keyboard Note Identification makes them alternate when both have questions available. Your Next Question setting controls when the switch happens. With Wait, click Next after reviewing your answer. You can change the filters while answering a question. Shuffle uses the updated list for the next question and returns to the tiles if the list is empty. Click the highlighted shuffle icon again to turn it off.

    During an exercise or lesson, Exercises / Lessons switches the list while keeping your activity on screen. Selecting an item starts or resumes it. The top-left pane button hides and shows the list without leaving your activity. Statistics and Browse database are at the top right. The sliders button opens the exercise’s own settings, and ? explains it.

    Glossary

    Open Glossary in the top toolbar to look up a term. Search for minor, for example, and select harmonic minor scale. You can hear the scale, try another example, or open a related exercise from the same page.

    Running the tests

    From a source checkout, install the development dependencies and run the test suite.

    .venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m pytest

    .\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
