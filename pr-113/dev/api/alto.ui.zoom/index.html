    alto.ui.zoom

    Zoom: make everything in Alto larger or smaller together.

    The zoom is a percentage, 100 by default, that moves through a list of steps. It scales the application font, every pixel and point length in the stylesheet, and the sizes the interface fixes in pixels, which are written with px here so that they follow it. The notation that is drawn by hand takes its size from the same percentage. Pressing Ctrl and Plus or Ctrl and Minus, or turning the mouse wheel with Ctrl held, moves one step, and Ctrl and 0 goes back to 100%. The choice is saved.

    Examples

    >>> set_percent(100)
False
>>> px(20), px(0)
(20, 0)
>>> css(
...     "QLabel { font-size: 14pt; border: 1px solid; }"
... )
'QLabel { font-size: 14pt; border: 1px solid; }'

    def set_percent(value: int) -> bool

    [Source]

    Zoom to the step nearest a percentage, save it and say so.

    Parameters

    • value (int): The percentage wanted.

    Returns

    • bool: True if the zoom changed, False if it was already there.

    Examples

    >>> set_percent(125)

    step

    def step(direction: int) -> bool

    [Source]

    Zoom in or out by one step.

    Parameters

    • direction (int): Positive to zoom in, negative to zoom out.

    Returns

    • bool: True if the zoom changed, False at the largest or smallest step.

    Examples

    >>> step(1), percent()
(True, 110)
>>> step(-1), percent()
(True, 100)
>>> while step(-1):
...     pass
>>> percent(), step(-1)
(50, False)
>>> reset(), percent()
(True, 100)

    WheelZoom

    WheelZoom(parent: QObject | None = None)

    [Source]

    Bases: QObject

    Zoom when the mouse wheel turns with Ctrl held, wherever the pointer is.

    A touchpad that sends small steps is added up, so that a whole notch is needed to move one step.

    Examples

    >>> WheelZoom().eventFilter(
...     QObject(), QEvent(QEvent.Type.None_)
... )
False

    Constructor

    Start with no wheel turned.

    Parameters

    • parent (QObject or None, default None): The object that owns the filter.

    Constructor examples

    >>> WheelZoom()._turned
0

    WheelZoom.follow

    def follow(app: QGuiApplication) -> None

    [Source]

    Watch the window that has the focus, and each window that gains it later, such as a dialog that opens.

    The filter goes on the windows, not on the application. A window is handed each wheel turn before the widget under the pointer is, so a turn anywhere in it is seen, while the many events that pass between the widgets inside it are not: a filter on the application runs for every one of those, which made building a page half as slow again.

    Parameters

    • app (QGuiApplication): The application whose windows to watch.

    Examples

    >>> handler = WheelZoom()
>>> handler.follow(app)

    WheelZoom.watch

    def watch(window: QWindow | None) -> None

    [Source]

    Zoom when the wheel turns with Ctrl held over a window.

    Parameters

    • window (QWindow or None): The window. None, which is what Qt passes when no window has the focus, does nothing.

    Examples

    >>> from PySide6.QtWidgets import QWidget
>>> widget = QWidget()
>>> widget.show()
>>> handler = WheelZoom()
>>> handler.watch(widget.windowHandle())
>>> handler.watch(None)
