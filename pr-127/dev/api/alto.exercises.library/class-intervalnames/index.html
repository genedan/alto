IntervalNames

class alto.exercises.library.IntervalNames Source

Bases: alto.exercises.base.Exercise

Name the interval between two written notes.

Examples

>>> q = IntervalNames().generate(
...     random.Random(3)
... )
>>> (
...     [len(chord) for chord in q.staff],
...     q.answer in q.choices,
... )
([2], True)

refresh(question: alto.exercises.base.Question) → alto.exercises.base.Question Source

Arrange written interval answers by quality, with interval numbers in columns.

Parameters

Parameter

Type

Description

question

Question

A new or saved interval question.
Returns

Type

Description

Question

The same answer choices in reading order. Perfect and major share a row.

Examples

>>> q = Question(
...     "",
...     choices=["d3", "m3", "P4", "M3", "A3"],
...     answer="m3",
... )
>>> IntervalNames().refresh(q).choices
['A3', 'M3', 'P4', 'm3', 'd3']
generate(rng: random.Random) → alto.exercises.base.Question Source

Make two notes whose interval is to be named.

Parameters

Parameter

Type

Description

rng

random.Random

The random number generator.
Returns

Type

Description

Question

The lower and higher note on a staff, and the interval (such as ‘M3’ or ‘P5’) as the answer.

Examples

...     random.Random(4)
